HTML-страницы собираются генератором build.py (GitHub Actions запускает его при каждом пуше).
Все правки внесены и в build.py, и в собранные HTML — при следующей сборке ничего не откатится.

## Локальный запуск
    cd alfa-expert
    python3 -m http.server 8000
    # открыть http://localhost:8000

## Публикация
Запушить содержимое папки в репозиторий ArtIgnat2000/alfa-expert (ветка main) —
GitHub Pages пересоберёт сайт автоматически.
