# Сайт-визитка экспертной организации «АЛЬФА»

Статический сайт (HTML + CSS + JS, без сборщиков и зависимостей). Открывается локально двойным кликом по `index.html`, разворачивается на любой хостинг простым копированием файлов.

## Как править содержимое

Все тексты, услуги, эксперты, цены, кейсы и FAQ вынесены в словари в начале `build.py`.
После правок:

```bash
cd site && python3 build.py
```

Страницы перегенерируются целиком — шапка, подвал и меню меняются во всех файлах сразу.
Если Python недоступен, можно править HTML напрямую, но тогда изменения в шапке/подвале нужно вносить в каждый файл.

## Что заменить перед публикацией

Обязательно (сейчас стоят заглушки в `ORG` в `build.py`):

- [ ] `legal`, `inn`, `ogrn` — юридическое наименование и реквизиты
- [ ] `phone_display` / `phone_href`, `phone2_*` — телефоны
- [ ] `email`, `address`, `hours` — почта, адрес, режим работы
- [ ] `site` — реальный домен (используется в canonical, sitemap, Schema.org)
- [ ] `WA`, `TG` — ссылки на WhatsApp и Telegram
- [ ] Блок статистики на главной: «10 000+ исследований с 2011 года» и др. — привести к фактическим, подтверждаемым документами значениям, либо удалить
- [ ] `EXPERTS` — реальные ФИО, образование, стаж, документы + деловые фотографии вместо плашек с инициалами (формат 4:5, класс `.expert__photo`)
- [ ] `SERVICES` — цены и сроки по действующему прайсу
- [ ] `CASES` — реальные обезличенные кейсы
- [ ] Карта на `kontakty.html` — вставить код Яндекс.Карт вместо блока-заглушки
- [ ] Юридические страницы — проверить у юриста под 152-ФЗ

## Форма заявки

Сейчас работает в демонстрационном режиме: валидация, маска телефона, drag & drop файлов и проверка ограничений (до 10 файлов, до 20 МБ) выполняются, но отправка имитируется.

Для боевого режима в `assets/js/main.js` (блок «ДЕМОНСТРАЦИОННАЯ ОТПРАВКА») замените `setTimeout` на реальный запрос:

```js
var fd = new FormData(form);
fetch('/api/lead.php', { method: 'POST', body: fd })
  .then(function (r) { if (!r.ok) throw new Error(); return r.json(); })
  .then(function () { /* успех */ })
  .catch(function () { /* ошибка */ });
```

Серверный обработчик должен: проверить типы и размеры файлов, отправить письмо на `info@…`, вести журнал обращений и отдавать JSON. Форму имеет смысл защитить от спама (honeypot-поле или капча). Загружаемые файлы содержат персональные данные — хранить их следует в закрытом от индексации каталоге.

## Реализованные требования ТЗ

| Требование | Как выполнено |
|---|---|
| Чёрно-золотая система по цветам логотипа | `#111111` / `#242424` графит, `#E0B84A` золото, `#F0C85A` яркое золото, `#F3E2A8` бледное золото |
| Светлый фон для информационных разделов | `#F7F6F2` и белый — основная часть страниц |
| Чёрный для первого экрана, доверия, CTA и футера | Секции `.section--dark`, `.hero`, `.cta-band`, `.footer` |
| Золото только акцентом | Иконки, номера этапов, тонкие линии, рамки, кнопки, цифры статистики. Длинных текстов золотом нет |
| Адаптивность прежде всего для смартфонов | Брейкпоинты 1080 / 940 / 760 px, базовый размер текста 16.5–17 px |
| Фиксированная кнопка «Позвонить эксперту» на мобильном | `.mobile-bar` — кнопка + WhatsApp |
| Телефон и мессенджеры всегда в шапке | Верхняя полоса и шапка, на мобильном — нижняя панель |
| Контраст | Основной текст `#242424` на `#F7F6F2` ≈ 13:1; `#EDEBE6` на `#111111` ≈ 15:1; кнопка — тёмный текст на золоте ≈ 5.6:1. Все значения выше порога WCAG AA |
| Группировка услуг по задачам клиента | Блок «В каких ситуациях мы помогаем» — 9 формулировок от проблемы, каждая ведёт на нужную услугу |
| Отдельная страница на каждую услугу | 6 страниц: вопросы эксперту, объекты, документы, сроки, цена |
| Вложения в заявке | Множественная загрузка, drag & drop, ограничения по числу и размеру |
| Информация о персданных до отправки | Обязательный чекбокс со ссылками на политику и согласие, форма не отправляется без него |
| Один шрифт заголовков + один для текста | Georgia (заголовки) и системный гротеск (текст), обе — системные, без внешних загрузок |
| Реальные фотографии экспертов | Подготовлены слоты 4:5 с пометкой о замене |
| Без «гарантий результата» | В FAQ и разделе для юристов прямо оговорено, что оценка доказательств — компетенция суда |
| Без стоковых судей и молотков | Только эмблема из логотипа и линейные SVG-иконки |

Дополнительно: разметка Schema.org (LegalService, Service, FAQPage), canonical, Open Graph, sitemap.xml, robots.txt, хлебные крошки, skip-link, `prefers-reduced-motion`, стили для печати.

## Публикация

Любой статический хостинг: скопировать содержимое `site/` в корень (`build.py` и `README.md` можно не выкладывать). Обязательно включить HTTPS — форма передаёт персональные данные.
